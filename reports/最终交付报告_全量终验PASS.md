## 六、关键技术加固成果（迭代 4.5.1 以来）

终验依托以下经实战验证的加固，全部已嵌入前后端并随服务生效：

| 加固项 | 问题根因 | 解决方案 | 实战验证 |
|---|---|---|---|
| **Crossref 第三检索源** | OpenAlex/S2 被 IP 级封禁（单请求也 429），限流闸防不住已生效封禁 | 接入 Crossref polite pool（mailto+UA），三源合并按 DOI+标题双键去重；verify_doi 增 Crossref 回退 | 解除 D2 证据 13 分封顶，0.677→0.899 |

| **五模块形状防御** | LLM 偶发直接返回 JSON 数组，`result.get()` 崩溃（题 79 得 6.0 分） | m1-m5 凡取值点防御 list/非 dict：list→包装、非 dict→fallback、数组杂质过滤 | 题 79 重跑 6.0→99.0；6 项单测全过 |

## 七、系统架构与前后端嵌入

```
前端层  React 18 + TypeScript + Vite 6 + Tailwind CSS（深色太空主题 · SSE 流式 · 力导向图）
        125题总控台（分级筛选/单题运行/批量运行/进度条/逐题报告导出）
        迭代工作台（证据卡三分类/假设树七要素/六维评分/计划五环节/版本对比时间线/人工反馈注入）
后端层  FastAPI + Python 3.11（JWT 认证 · 多智能体编排 · SSE · Mock 降级 · 双推理引擎）
        六环节流水线 m1_question → m2_evidence → m3_hypothesis → m4_verify → m5_plan → m6_orchestrator
推理层  阿里云百炼 DashScope（Qwen-Max/Plus/Turbo）│ 本地 Ollama（Qwen2.5）│ Mock 降级
存储层  SQLite（questions_125/pipeline_runs/evidence_cards/hypotheses_v2/plans_v2/
        iteration_rounds/feedback_entries/run_evaluations/iteration_log/question_splits 等）+ FTS5
```
