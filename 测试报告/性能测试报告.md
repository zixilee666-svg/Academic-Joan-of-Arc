# 性能测试报告 — Academic Joan of Arc

- **生成日期**：2026-08-31
- **目标**：评估系统在典型负载下的响应延迟、流式吞吐与并发能力

## 1. 关键性能指标（建议）

| 指标 | 目标 | 说明 |
|------|------|------|
| 单 Agent 首字延迟（TTFT） | < 3s（百炼 qwen-plus） | 依赖百炼平台网络与模型 |
| 假设生成端到端耗时 | < 30s | 多 Agent 串联 |
| `/api/stats/dashboard` 查询 | < 200ms | 本地 SQLite 聚合 |
| 并发会话 | ≥ 20 | uvicorn + async |
| SSE 流式稳定性 | 无中断 | run-agent-stream |

## 2. 可观测能力（已实现）

- `GET /api/stats/dashboard`：实时统计会话/假设/文献/图谱规模；
- `GET /api/agent/logs`：Agent 调用延迟（latency_ms）与 Token 消耗记录；
- 推理引擎 `health_check`：模型就绪状态与可用模型列表。

## 3. 测试方案（需人工执行）

1. **接口压测**：使用 `locust` 或 `artillery` 对 `/api/chat`、`/api/research/run-agent` 施加阶梯并发，记录 P50/P95 延迟与错误率。
2. **流式吞吐**：对 `run-agent-stream` 测量 token/s 与断流率。
3. **数据规模**：向 SQLite 灌入 ≥1000 条文献与假设，验证 dashboard 与检索在大数据量下的耗时。

## 4. 当前状态

性能采集埋点（agent_logs.latency_ms、token 计数）已就绪；**正式压测需在具备推理引擎的环境执行**（百炼/本地 Ollama），本报告提供指标定义与可执行方案，供人工在提交前补全数据。
