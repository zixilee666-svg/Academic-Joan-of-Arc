# 集成测试报告 — Academic Joan of Arc

- **生成日期**：2026-08-31
- **目标**：验证端到端 API 链路（前端 → FastAPI → 推理引擎/SQLite）在真实运行栈下的连通性与业务正确性

## 1. 已覆盖接口（需运行栈后执行）

| 接口 | 方法 | 验证内容 |
|------|------|----------|
| `/health` | GET | provider / llm 健康 / database 连接 |
| `/api/auth/login` | POST | JWT 签发与校验 |
| `/api/research/run-agent` | POST | 单 Agent 调用（各 stage） |
| `/api/research/hypothesis` | POST | 假设生成 |
| `/api/research/plan` | POST | 十大字段研究计划生成 |
| `/api/literature/search` | GET | FTS5 文献检索 |
| `/api/knowledge/graph` | GET | 知识图谱节点/关系 |

## 2. 测试方法（推荐）

使用 HTTP 客户端（curl / pytest + httpx / Postman）对 `http://localhost:8000` 进行串联调用，断言状态码与关键字段；前端经 `npm run dev` 手动走查“登录→问题→文献→假设→计划”闭环。

## 3. 当前状态

- 后端编排单测已通过（见单元测试报告），接口逻辑就绪；
- **完整端到端执行需在具备推理引擎的环境下运行**（LLM_PROVIDER=bailian 并配置 DASHSCOPE_API_KEY，或 LLM_PROVIDER=ollama 且本地已拉起模型）。
- 在引擎不可用时系统自动降级 Mock，接口仍返回 200 与结构化内容，可先以 Mock 模式完成连通性集成测试。

## 4. 复现步骤（百炼模式）

```bash
cp .env.example .env
# .env: LLM_PROVIDER=bailian ; DASHSCOPE_API_KEY=<你的KEY>
docker-compose up -d
curl http://localhost:8000/health
curl -X POST http://localhost:8000/api/research/plan -H "Content-Type: application/json" \
  -d '{"question":"太阳活动区磁螺度累积是否先于耀斑？","literature":"...","hypothesis":"...","experiment":"..."}'
```
